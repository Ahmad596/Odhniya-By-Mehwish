# Odhniya By Mehwish Website
Responsive multi-page HTML/CSS/JS website built from the uploaded 6-page design template.

## Structure
- `index.html` — Home
- `pages/` — About, careers, collection, contact, and category pages
- `css/style.css` — all styling
- `js/main.js` — mobile navigation and footer year
- `assets/images/` — images extracted from your PDF template

## Run
Open `index.html` in a browser. No framework or build step is needed.

## Customize
Replace Instagram/WhatsApp/email placeholders in `pages/contact.html`. Product names and prices can be added in the category pages if you provide them; the PDF template contains category descriptions and photos but no specific SKU/price data.

## Careers
The Careers page is available at pages/careers.html and linked in every header and footer. Career areas are illustrative, not advertised vacancies. Add confirmed vacancies, application instructions, and recruitment contact details when available.
